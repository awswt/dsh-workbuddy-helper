- 测试：220 条通过（21 个测试文件）

## 本次新增与修复

- **新增**：设置里多了一页「WorkBuddy 登录」（`settings.section` + `settings.section.icon`，`order` 25，排在「插件」之后）。以前只有会话输入框旁的「会话辅助」面板能登录——那一栏是按会话的；一个从没开过会话、或那一栏被别的插件挤掉的用户，找不到登录入口。现在整台机器的账号在设置里就能管。
- **新增**：那一页是自成一体的卡片——区域选择（国内版/国际版）、开始登录、打开扫码页、我已完成（轮询）、账号列表（可用/过期/可刷新）、刷新、移除，以及只读列出 `dsh-connect-workbuddy` 的旧账号并一键导入。全部走本插件自己的 `/dsh-workbuddy-helper/accounts` 路由，不碰对方的存储。
- **修复**：设置页的两个槽位各自 `try/catch` 且与 composer 的注册互不牵连。老宿主没有 `settings.*` 时，`apply()` 不再连带把「会话辅助」按钮一起废掉——失败只 `console.error` 留一行。
- **修复**：图标注册的 id 与页面注册的 id 强制相同。宿主按 id 配对，`unmatched ids never render`——id 打错不会有任何报错，只会静默少一个图标。
- **测试**：新增 `test/settings-card.test.mjs`（4 条）——两条注册存在且 id 一致、id 不借用官方席位、缺 `settings.*` 时 pill 仍在、样式进了同一张样式表。全量 216 → 220。
