# v0.8.3

- 发布版本：`v0.8.3`
- 上一个版本：`v0.8.2`
- 提交说明：fix(client): stop the composer pill dying when the dialog opens
- 测试：226 条通过（22 个测试文件）

## 本次新增与修复

- 修复：会话辅助按钮点一次就永久消失——PickerDialog 里的条件 return 排在两个 hook 前面，点开那一帧 React 抛 `Rendered more hooks than during the previous render`，宿主 SlotErrorBoundary 对非 chain 槽位直接把整个 entry 退役，pill 与弹窗共用一个 entry 于是陪葬
- 修复：把关闭态早退挪到最后一行 hook 之后，hook 数量在开关两态保持一致
- 新增：DialogBoundary 错误边界 + 弹窗只在打开时挂载，以后弹窗真崩了只丢弹窗，pill 永远活着
- 新增：test/hook-order.test.mjs 4 条静态审计（不依赖模拟 React 调度），扫描所有组件抓 `条件 return 站在 hook 前面`，并守 DialogBoundary 与弹窗挂载条件
- 修改：设置页导航名从「WorkBuddy 登录」改成 workbuddy-helper（README、AGENTS、测试同步）
